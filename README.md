# BBC Search

AI Coding 练手项目：搜索双语电视剧台词，并播放、分享对应短视频素材。

## MVP

- 英文/中文关键词搜索
- 双语台词结果
- 剧集/时间信息
- 对应短视频播放
- 独立素材分享页

## Proposed stack

- Next.js + TypeScript
- Supabase Postgres
- Cloudflare R2
- Python + FFmpeg
- Vercel
